# Что сделано

## 2026-10-11

- Подписи интерфейса короткими фразами без тире и точек с запятой; в строке прогресса «без N» стало «без субтитров N».
- Код интерфейса: понятные имена вместо однобуквенных, комментарии короткими простыми фразами.
- Код сервера: понятные имена вместо однобуквенных, комментарии короткими простыми фразами.
- На телефоне раскрытый список каналов больше не сворачивается сам, когда кончается индексация (#10).
- На узком экране плеер больше не закрывает конец списка: отступ считается от настоящей высоты плеера (#9).
- Полоска паузы после блокировки идёт ровно до конца паузы и не прыгает на обновлениях (#8).
- Светлая тема: цвета состояний (ошибка, пауза, готово) затемнены до контраста 7:1, второстепенный текст — до 5,6:1 (#11).
- Запись большого канала на диск больше не останавливает поиск и обновления интерфейса (#7).
- Канал, удалённый во время получения списка видео, больше не возвращается сам (#6).
- Без сети видео больше не помечаются ошибкой, а задание — «готово»: пауза 10–80 с и повтор, после пяти сбоев подряд остановка с понятной причиной (#5).
- Индексация, остановленная блокировкой, сама продолжается после паузы; после перезапуска продолжаются и каналы без полученного списка видео (#4).
- Второй сервер на той же папке данных не запускается (блокировка `flock`), занятый порт останавливает запуск до индексации (#3).
- Видео моложе недели «без субтитров» перепроверяется при обновлении, не чаще раза в 6 часов (#2).
- Запасной путь скачивания субтитров через yt-dlp (флаг `-ytdlp`, по умолчанию — если есть в `PATH`): при PO-токене и непонятных ответах YouTube, но не при блокировке адреса.
- Поиск склеивает вхождения на соседних строках в одно совпадение (до 6 строк): строки контекста больше не повторяются подряд.
- Предупреждение, если DNS сети включает «Безопасный режим» YouTube (Restricted Mode): проверка при запуске и перед каждой индексацией.
- Удалена прежняя версия на Node.js (`server.js`, `package.json`). Её `cache.json` новая версия не читает: каналы добавляются заново.
- Интерфейс на Angular (`web/`), вшит в бинарник: список каналов с живым прогрессом индексации, поиск с подсветкой и контекстом, один плеер с переходом к метке времени, светлая и тёмная темы, раскладка от 320 px. Сборка — `./tasks.sh`.
- Сервер переписан на Go (`server/`): поиск канала через YouTube Data API, скачивание субтитров без ключа, фоновая индексация с общей очередью и паузой после блокировки, хранение по файлу на канал, поиск фраз через границы строк, API и поток SSE.
